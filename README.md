# AI 학사 문서 도우미

**[서비스 열기](https://inha-guide-ai-week10-demo.streamlit.app/)**

학교 공식 학사자료에서 질문에 맞는 정보와 출처를 찾는 AI캡스톤디자인10주차 시연 서비스입니다.
Streamlit Community Cloud에서 실행하므로 개발자 PC를 켜 두지 않아도 접속할 수 있습니다.
휴면 상태에서는 처음 열 때 준비 시간이 걸릴 수 있습니다.

## 지원 범위와 자료

- 졸업요건: 총 졸업학점·전공/교양 최소학점.
- 교과과정:2026학년도 AI소프트웨어학과1~3학년의 학년·학기·과목·학점·이수구분.
- 학과 로드맵:AI·BigData 트랙의 학습 흐름.
- 대체과목:공식 설정표의 직접 관계 및 대체수강 조건.
- 자격증 학점인정:정보처리산업기사 인정학점·매칭과목·신청 조건.

공식 PDF6개와 교과과정 자료를 사용하며 검색 정보 단위는105개입니다.
저장한 공식자료 이후의 변경을 자동 반영하지 않습니다. 다른 학과·연도·과정에 임의 확대 적용하지 않습니다.
장학금·등록금·일반 행정·외부 자격시험 접수·과제 코드 작성은 지원하지 않습니다.

## 모델과10주차 개선

Word TF-IDF + Character TF-IDF + Logistic Regression6클래스 모델로 질문을 분류하고,
구조화 조회와 multilingual-e5-small + ChromaDB로 근거를 찾습니다.
답변은 기존 템플릿과 공식자료를 사용하며 외부 생성형 AI API를 사용하지 않습니다.

기본 모델은8주차300문항 모델, confidence threshold는0.50입니다.
10주차에는 배경 설명과 실제 요청을 구분하는 routing을 보완했습니다.
모델 재학습·E5 fine-tuning·corpus 변경은 하지 않았습니다.

수정 전에 새로 고정한 **개발자 작성 합성 경계 질문60개**의 첫 평가에서
최종 Intent 정확도33/60(55.00%) →57/60(95.00%), Macro F1 0.5345 →0.9497이었습니다.
같은 세트의 raw 모델 정확도는39/60(65.00%)로 동일합니다.
이 수치는 실제 학생 전체 성능이나 답변 사실 정확도95%를 의미하지 않습니다.
관찰된 이전 질문의 개발 성적과 분리했고 최종 오답3개도 보존했습니다.

로컬 기존 회귀270/270, 신규 경계 unit13/13, 추가 답변 AppTest12/12를 통과했습니다.
클라우드에서 데이터105개·대표 질문9개·공식 PDF 다운로드를 별도로 확인했습니다.
학습·평가 코드와 질문·정답·전후 예측은 별도 원본 프로젝트의 제출·실험 기록에 보존합니다.
이 저장소는 서비스 실행용27파일만 포함하는 배포본입니다.

## 로컬 실행

Python3.12에서 다음을 실행합니다.

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

API 키나 `.env`는 필요하지 않습니다. 첫 실행에는 고정된 공개 E5 모델을 다운로드하므로 네트워크가 필요합니다.
ChromaDB 디렉터리는 실행 중 내부 기록을 쓸 수 있어야 합니다.
모델·DB를 재학습하거나 재구축하는 명령은 실행에 필요하지 않습니다.

Cloud 설정:branch `main`, entrypoint `app.py`, Python3.12, 비밀 설정 없음.
Streamlit1.60.0의 HTTP 압축 처리 호환성을 위해 로컬 검증 버전인 Starlette1.3.1을 고정했습니다.
